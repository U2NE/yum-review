# 요구사항

## 확인된 요구사항

- 리뷰는 식당 전체가 아니라 식당의 개별 메뉴에 연결한다.
- 식당 정보는 해당 식당의 메뉴를 모아 보여주는 데 사용한다.
- 실제 계정과 데이터베이스에 저장되는 리뷰를 제공한다.
- 메뉴 리뷰에는 전체 별점, 맛·가성비·양 세부 별점, 코멘트를 포함한다.

## 추가 정의 필요

메뉴·식당 카탈로그 관리, 사진, 콘텐츠 신고·운영, 배포는 MVP에서 제외한다. 사용자가 Spring Boot를 선택했고 DB는 PostgreSQL을 제안한다. React·TypeScript 화면과 Spring Boot REST API를 한 프로젝트로 구성하는 안은 사양 승인 대기 중이다.
