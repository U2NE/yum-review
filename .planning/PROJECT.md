# 프로젝트: Yum Review

## 제품 방향

각 식당의 개별 메뉴를 찾아보고 리뷰하는 서비스다. 리뷰의 중심은 식당 전체가 아니라 식당에서 판매하는 메뉴다. 식당은 메뉴를 묶고 찾아가기 위한 상위 정보로 다룬다.

## 확인된 범위

- 실제 사용자 계정과 저장되는 리뷰를 갖춘 웹 MVP를 만든다.
- 리뷰는 메뉴별 전체 별점, 맛·가성비·양 세부 별점, 코멘트로 구성한다.
- 식당은 메뉴를 묶고 찾아가기 위한 상위 정보로 다루며 식당 자체 평점은 제공하지 않는다.

## 아직 정하지 않은 내용

메뉴·식당 등록 주체, 사진, 운영·신고 정책은 MVP 사양에서 후속 범위로 남긴다. 기술 기반은 Spring Boot로 정했고 DB는 PostgreSQL을 제안한다.
