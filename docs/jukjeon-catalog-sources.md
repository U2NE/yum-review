## 데이터 사용 범위

- NAVER Local Search API 응답은 데이터베이스에 저장하지 않았다. 위 두 장소는 브라우저의 장소 화면을 사람이 확인해 필요한 매장/메뉴 사실만 옮겼다.
- Naver Place 메뉴 사진과 방문자 사진을 내려받거나 저장하지 않았다. 곰포차 죽전점 사진은 네이버에서 가져온 것이 아니라 사용자가 직접 제공한 파일이다.
- 매장 위도·경도는 건물 단위의 허용된 지오코더에서 독립 확인하지 못해 DB에 입력하지 않았다. 반경 필터 결과는 좌표가 추가되기 전까지 이 매장들을 제외한다.
- 값이 확인되지 않은 음식 설명, 영업 상태, 영업시간, 다른 가게/메뉴는 추가하지 않았다.
- 카탈로그는 수동 검증의 작은 시작점이며, 가격은 변경될 수 있으므로 매장 측 최신 정보로 재확인해야 한다.

## 초기 카탈로그의 범위와 한계

볶신단국대점은 맥주·호프 분류와 장소 메뉴를 확인해 등록했지만, 해당 목록의 업주 관리 여부와 가격 최신성은 페이지에서 독립 검증할 수 없다. 이 출처와 그 한계를 화면에 연결된 지도 링크 및 이 기록에 남겼다. 뚱띵이 알찜과 곱창전골은 메뉴를 확인할 수 없어 비워 두었다. 곰포차 죽전점의 메뉴 가격은 사용자가 제공한 사진 파일명 기준이라 매장 최신 가격과 다를 수 있다. 현재 카탈로그는 세 곳으로 제한적이며, 주점 메뉴 가격은 매장 확인 전 참고값이다.

V4/V5 시드는 이름이 충돌하는 기존 매장·메뉴를 덮어쓰지 않는다. 메뉴는 매장명과 전체 주소가 모두 일치하는 경우에만 연결하므로, 같은 이름에 다른 주소를 가진 기존 매장은 변경하지 않는다.
