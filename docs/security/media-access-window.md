# 사진 URL의 남은 접근 시간

앱은 비공개 Storage의 사진을 표시할 때 최대 15초짜리 서명 URL을 발급한다. 사진 연결을 해제하면 DB 상태와 RLS가 새 URL 발급을 막지만, 이미 발급한 서명 URL 자체는 만료되기 전까지 다시 요청될 수 있다. 따라서 Storage가 새 응답을 제공할 수 있는 최대 잔여 창은 마지막 URL 발급 시각부터 최대 15초다.

현재 업로드는 객체 캐시 수명을 3,600초로 요청한다. 브라우저가 이미지 응답을 캐시하면 같은 기기에서 최대 1시간 동안 다시 표시될 수 있으며, 사용자가 내려받거나 별도로 저장한 바이트는 원격에서 회수할 수 없다. 서명 URL의 Storage 접근 만료와 브라우저 캐시 수명은 별개의 한도다. 실제 Supabase Storage가 이 만료·캐시 헤더를 그대로 적용하는지는 disposable local Storage에서 별도로 확인해야 한다.
